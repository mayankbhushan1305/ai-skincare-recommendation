## 💡 About The Project

**Glow Sense** is a modern, responsive web application designed to give users tailored skincare routines and product recommendations. Whether you are dealing with acne, dryness, aging, or dullness, Glow Sense analyzes your unique profile or quiz inputs to curate the ideal daily regimen.

---

## ✨ Features

- **🎯 Skin Type & Concern Matching:** Select your specific skin type (Oily, Dry, Sensitive, Combination) and target concern (Acne, Pigmentation, Aging, Dullness) for custom routines.
- **🧠 Interactive Skin Quiz:** Take a quick built-in diagnostic quiz to discover your true skin type automatically.
- **💅 Modern Glassmorphism UI:** Features an aesthetic gradient background, responsive card layouts, smooth animations, and FontAwesome icons styled with Google Fonts (Poppins).
- **⚡ Lightweight & Fast:** Built natively with Flask and vanilla front-end styles for fast execution without heavy bloat.

---

## 🛠️ Technologies Used

- **Backend:** Python, Flask
- **Frontend:** HTML5, CSS3, Jinja2 Templates
- **Styling & UI:** Google Fonts (Poppins), FontAwesome 6, Custom Glassmorphism Gradients
