# Skincare AI Recommendation System

This project is a simple AI-based skincare recommendation web application built using Python and Flask.

Features
- User selects skin type
- System provides skincare recommendations
- Simple web interface

Technologies Used
- Python
- Flask
- HTML

How to Run

1. Install Flask
pip install flask

2. Run the application
python app.py

3. Open browser
http://127.0.0.1:5000/
